Step 0

Prerequisites

Two accounts and one decision about money. If you already have an Azure subscription you can create resources in, skim this and move on.

About 20 minutes · Do this before the workshop if you can

Doing this the night before?

Please do. Card verification and subscription activation can take a few minutes, and occasionally much longer. Everything on this page is account admin — nothing here is about agents, so it's the ideal thing to get out of the way early.

1. A GitHub account

You'll fork the workshop repository and edit it in GitHub Codespaces, a dev environment that runs in your browser. That means no Python, Node or Azure CLI installs on your laptop.

  1. If you don't have one, sign up at github.com/signup.
  2. Verify your email address. Codespaces won't start until you do.

Free personal accounts include a monthly allowance of Codespaces hours, which is more than enough for this workshop. See GitHub's billing docs for the current limits. You'll stop your Codespace in Step 10.

2. An Azure subscription

A subscription is the thing Azure bills. Every resource you create lives in one. You need a subscription where you're allowed to create resources — if you're using a work account, that permission is not a given.

If you're starting from nothing

  1. Go to azure.microsoft.com/free and select Start free.
  2. Sign in with a Microsoft account, or create one.
  3. Fill in your profile, then verify by phone and by card. The card is for identity verification. You are not moved to paid rates until you choose to upgrade.
  4. Accept the agreement. Activation usually takes a couple of minutes.
  5. Go to portal.azure.com. You should land on a dashboard.

A new free account comes with a credit to spend in your first 30 days, plus a set of services that are free for 12 months. The credit comfortably covers this workshop.

If you're using a work or school account

Check two things before the workshop, because only an administrator can fix them:

  • Can you see a subscription? In the portal, search for Subscriptions. If the list is empty, you don't have access to one.
  • Can you create things in it? You need the Contributor role (or Owner) on a subscription or resource group. Open the subscription, select Access control (IAM) → View my access.
The one that bites people

Creating the resources in Step 1 needs Contributor. Step 1 also has you grant yourself a role, which needs Owner or User Access Administrator. If your work subscription only gives you Contributor, use a personal free subscription for the workshop instead — it's far quicker than waiting on an admin.

3. Know what you're spending

Three things in this workshop can cost money, and only the first one really does:

So the real cost of this workshop is forgetting to delete things. Two habits protect you, and you'll set both up in Step 1: put everything in one resource group so a single delete removes it all, and set a budget alert.

4. What you do not need

No Python, Node.js, Azure CLI, Docker or Git installed locally — Codespaces brings all of it. You need a browser and a reasonable internet connection. Chrome and Edge are the safest choices for Codespaces.

Checkpoint

Before moving on, confirm all three:

  • You can sign in at github.com and your email is verified.
  • You can sign in at portal.azure.com.
  • Searching for Subscriptions in the portal shows at least one subscription.

If something went wrong

My card was declined, or verification keeps failing

Virtual and prepaid cards are often rejected. Use a normal credit or debit card. Some banks block the verification charge as suspicious — approving it in your banking app and retrying usually works. If it still fails, contact Azure support; they can verify accounts manually.

The Subscriptions list is empty

Usually you're signed in to the wrong tenant. Select your account picture in the portal → Switch directory, and check the other directories listed. If you're on a work account and there's genuinely nothing, ask whoever manages Azure for Contributor access on a resource group, or create a personal free subscription.

I already used my free trial and can't start another

That's fine. Switch the subscription to pay-as-you-go. This workshop's actual usage is a matter of cents, provided you complete Step 10. Set the budget alert in Step 1 so you find out immediately if that stops being true.
